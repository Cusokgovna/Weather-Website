Frequently asked questions

Weather data

Where does weather data come from?

We use OpenWeather: geocoding, current weather, 5-day/3-hour forecast and air quality. Requests go through our server, so the API key is never sent to the browser.

How to enable geolocation?

Click "My location" and allow geolocation access in the browser. If access is denied — use the search field.

How to change theme?

Click 🌓 in the header. Guests keep the choice in the browser, signed-in users — in their account settings.

Account and privacy

Why do I need an account?

An account lets you save favorite cities, see your search history and keep your theme on any device.

How is my data stored?

Accounts are stored in a Microsoft SQL Server database. Passwords are hashed with scrypt and are never stored as plain text; sign-in uses an HttpOnly session cookie.
