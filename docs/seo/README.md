«До» — исходная версия сайта (не было `meta description`), «после» — сайт, запущенный в Docker (`docker compose ... up`).

## Что сделано

- **Базовые метатеги** на каждой странице: `lang`, `charset`, `viewport`, свой `title` и `description` (главная, FAQ, профиль, 404); `canonical` и Open Graph на публичных страницах.
- **Структура заголовков**: раньше `<h1>Weather</h1>` стоял в логотипе на всех страницах — теперь логотип это ссылка, а на каждой странице ровно один `<h1>` с названием страницы; уровни идут без пропусков (`h1` → `h2`), размер задаётся CSS-классами (`.page-title`, `.card-title`).
- **Понятные URL**: `/faq`, `/profile` вместо `/faq.html`; старые адреса `*.html` отдают редирект 301 на новые.
- **robots.txt** (`public/robots.txt`): закрыты `/profile` (личный кабинет) и `/api/`; отдельная группа для Яндекса с `Clean-param` для UTM-меток; строка `Sitemap`.
- **sitemap.xml** (`public/sitemap.xml`): только публичные страницы (`/`, `/faq`) с абсолютными адресами `https://example.com/...` — заменить на реальный домен при публикации.
- **noindex**: `<meta name="robots" content="noindex">` на странице профиля и на странице 404. Вход/регистрация — модальное окно, отдельной страницы нет.
- **X-Robots-Tag** для API: middleware в `server/app.js` добавляет `X-Robots-Tag: noindex, nofollow` ко всем ответам `/api/*`.
- **Скорость**: у изображений заданы `width`/`height`, шрифт подключён с `display=swap`, геолокация больше не запрашивается при загрузке страницы (только по кнопке).

Всё это проверяется автотестами в `tests/api.test.js` (они же запускаются в GitHub Actions).

## Что осталось и почему

- Страница профиля закрыта и в `robots.txt`, и через `noindex` — так требует задание. На практике Google и Яндекс советуют что-то одно: если страница закрыта в `robots.txt`, робот не скачает её и не увидит `noindex`. Профиль доступен только после входа, поэтому в поиск он и так не попадёт.
- `og:image` указывает на `https://example.com/og-image.png` — картинку превью нужно добавить, когда у проекта появится домен.
- Карта сайта написана вручную (страниц всего две). Если появятся страницы, создаваемые из базы данных (например, страница каждого города), sitemap лучше генерировать на бэкенде.
- В моём замере «после» в Best Practices была ошибка консоли 503 — это потому, что сайт был запущен без `OPENWEATHER_KEY`. С ключом её нет. На SEO это не влияет.
